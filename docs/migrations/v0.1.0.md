# Socle v0.1.0

Première version publiée du socle, posée sur le jalon 6. Il n'y a pas de
version antérieure : une boutique créée depuis ce tag l'est par
`shopctl new --core v0.1.0`, pas par une mise à niveau.

Ces notes ont été écrites **après** le tag, au jalon 9, quand la publication est
devenue une porte. Le tag lui-même ne les porte pas — il est immuable et ne sera
pas déplacé pour les y ajouter (ADR 0003) ; elles vivent ici, dans l'historique
qui suit, pour que la série des versions soit lisible d'un bout à l'autre.

## Ce qui change

- le socle français : catalogue typé, formats `fr-FR`, storefront et
  administration traduits, TVA et facturation cadrées (jalons 3 et 5) ;
- l'import de catalogue idempotent depuis un CSV (jalon 4) ;
- la CLI `shopctl` : création, dépôt GitHub, provisioning, catalogue,
  déploiement et destruction (jalons 2, 4 et 6) ;
- quarante-trois migrations D1, de `0001` à `0043`.

Le paiement éprouvé, la porte de sécurité, la sauvegarde et la mise à niveau de
flotte arrivent en `v0.2.0`.

## Migrations

Toutes celles du dépôt. Une boutique neuve les applique à son provisioning ;
aucune ne s'applique à une base existante, puisqu'il n'en existe pas.

## À faire dans la boutique

Rien. La création rend le manifeste, le thème et la configuration Wrangler.

## Compatibilité

Sans objet : c'est la première version.
