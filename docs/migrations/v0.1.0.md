# Socle v0.1.0

Première version publiée du socle. Il n'y a pas de version antérieure : une
boutique créée depuis ce tag l'est par `shopctl new --core v0.1.0`, pas par une
mise à niveau.

## Ce qui change

- le socle français complet : catalogue typé, formats `fr-FR`, storefront et
  administration traduits, TVA et facturation cadrées (jalons 3 et 7) ;
- la CLI `shopctl` : création, dépôt, provisioning, catalogue, déploiement,
  sauvegarde, restauration, destruction (jalons 2, 4, 6 et 8) ;
- quarante-trois migrations D1, de `0001` à `0043`.

## Migrations

Toutes celles du dépôt. Une boutique neuve les applique à son provisioning ;
aucune ne s'applique à une base existante, puisqu'il n'en existe pas.

## À faire dans la boutique

Rien. La création rend le manifeste, le thème et la configuration Wrangler.

## Compatibilité

Sans objet : c'est la première version.
