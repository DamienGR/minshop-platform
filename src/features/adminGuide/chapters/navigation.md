## Navigation

Les menus de votre boutique : l’**En-tête**, en haut de chaque page, et le **Pied de page**, en bas.

### Ajouter un lien

1. Dans **Ajouter un élément**, choisissez le **Type** : une page, un produit, une catégorie, l’accueil ou le catalogue.
2. Choisissez l’élément dans la liste. Tapez quelques lettres pour le trouver.
3. Le **Libellé** est le texte du lien. Vide, il reprend le nom de l’élément.
4. Dans **Ajouter à**, choisissez le menu, puis cliquez sur **Ajouter**.

Le lien apparaît sur la boutique en moins d’une minute.

### Ranger les liens

- Les flèches ↑ et ↓ changent l’ordre.
- **Modifier le texte du lien** change le texte affiché.
- La croix × retire le lien du menu. La page ou le produit, eux, restent.

### Un lien invisible

Un lien vers une page en brouillon ou un produit inactif est marqué « invisible sur la vitrine » : il ne s’affiche pas. Publiez la page, réactivez le produit, ou retirez le lien.
